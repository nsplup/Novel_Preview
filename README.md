# Novel_Preview

一个用于 **HFS（HTTP File Server）** 的在线阅读插件。无需下载文件，直接在浏览器中打开服务器上的 `.txt` / `.md` 文件，自动识别编码、切分章节、保存阅读进度，提供接近原生阅读器的体验。

---

## ✨ 功能特性

### 阅读体验

- **在线阅读**：在文件右键菜单中新增「📖 在线阅读」入口，无需下载即可打开文本文件
- **自动编码识别**：支持 UTF-8 / GB18030 / Big5 / UTF-16LE / UTF-16BE / Shift-JIS / EUC-JP / Windows-1252 / ISO-8859-1，并处理 BOM
- **流式下载与解码**：分块读取文件（每 1 MB 一段），大文件也不会卡死页面，实时显示进度
- **智能章节切分**：自动识别「第 N 章 / 第 N 回 / 第 N 节 / 序章 / 楔子 / 番外 / Chapter N / 卷 N」等标题格式，并排除「第一节课」「第三部分」等边缘干扰
- **字号调节**：13 – 42 px 区间内可调，保存于 localStorage，切换章节时自动定位当前阅读行
- **沉浸式全屏**：移动端自动请求全屏，点击正文可切换工具栏显隐

### 目录与进度

- **虚拟滚动目录**：无论书籍有多少章都能流畅渲染，自动定位到当前章节
- **阅读进度保存**：按文件路径独立记录每章滚动位置，下次打开自动续读
- **目录概览**：显示总章节数、已读章节数、每章读到第几行

### 全文搜索

- 支持**章节标题**与**正文内容**的双重匹配
- 结果高亮显示命中位置及上下文
- 上限 300 条（超出提示「结果过多」）
- 结果以虚拟列表渲染，支持点击跳转并闪烁高亮目标行
- 输入法合成中不触发搜索，防抖 200 ms

### 界面

- 自动跟随 `prefers-color-scheme` 深色模式
- 提取宿主页面背景色，动态匹配主题色与对比度
- 移动端安全区适配（`env(safe-area-inset-*)`）
- 键盘支持：`Esc` 逐级关闭（搜索 → 目录 → 阅读器）

---

## 📦 安装

1. 将 `main.js` 放入 HFS 的插件目录（通常为 `plugins/` 下新建一个目录）
2. 在 HFS 后台启用该插件
3. 刷新页面，右键点击任意 `.txt` / `.md` 文件 → 选择「📖 在线阅读」

## 🗂️ 支持的文件类型

| 扩展名 | 说明                                     |
| ------ | ---------------------------------------- |
| `.txt` | 纯文本                                   |
| `.md`  | Markdown（以纯文本方式阅读，不渲染语法） |

> 如需扩展类型，可修改源码中的 `TEXT_EXTENSIONS` 常量。

## ⌨️ 快捷键

| 按键                | 行为                             |
| ------------------- | -------------------------------- |
| `Esc`               | 关闭搜索 → 关闭目录 → 退出阅读器 |
| `Enter`（搜索框内） | 立即执行搜索                     |

## 🛠️ 技术要点

- **零依赖**：纯原生 JS，无第三方库
- **虚拟列表**：DOM 元素回收 + 元素池复用，章节列表与搜索结果都可承载万级条目
- **分块解码**：`TextDecoder` 流式解码，配合 `nextFrame()` 让出主线程，避免大文件阻塞
- **会话保护**：每次打开递增 `session` 标记，避免快速切换文件时旧任务的异步回调污染新状态
- **ResizeObserver**：容器尺寸变化自动重新计算虚拟列表可视区

## ⚙️ 主要常量

如需定制，可在 `main.js` 顶部调整：

```js
const FONT_DEFAULT = 19    // 默认字号
const FONT_MIN     = 13    // 最小字号
const FONT_MAX     = 42    // 最大字号
const FONT_STEP    = 2     // 每次调节步进

const SEARCH_MAX   = 300   // 搜索结果上限
const DECODE_CHUNK = 1024 * 1024  // 解码分块大小 (1MB)
const SAVE_DELAY   = 700   // 进度保存防抖 (ms)

const TOC_ITEM_H   = 48    // 目录项高度
const SEARCH_ITEM_H = 66   // 搜索结果项高度
```

## 💾 数据存储

所有数据保存在浏览器 `localStorage`，不会上传到服务器：

| Key                                 | 内容                                 |
| ----------------------------------- | ------------------------------------ |
| `Novel_Preview.fontSize`            | 用户设定的字号                       |
| `Novel_Preview.progress.<文件路径>` | 该文件的阅读进度（章节 → 行号 映射） |

## 🧩 事件挂钩

插件通过 HFS 的事件系统注册文件菜单项：

```js
HFS.onEvent('fileMenu', ({ entry, menu }) => {
  if (isTextFile(entry) && !entry.isFolder) {
    menu.push({
      id: PLUGIN_NAME,
      label: '在线阅读',
      icon: '📖',
      onClick: () => open(entry)
    })
  }
})
```
