## 功能特性

### 📖 核心阅读功能
- **多格式支持**：完美解析TXT/MD文本文件
- **智能章节识别**：自动检测中英文章节结构
  - 支持多种标题格式：第X章、Chapter X、卷X等
  - 智能分页算法（每500段自动分页）
- **编码自动检测**：支持10+种常见编码格式
  - UTF-8, UTF-16, GBK, GB18030, BIG5
  - Shift_JIS, EUC-JP, ISO-8859-1等

### ⚡ 性能优化
- **流式处理**：1MB分块解码大文件
- **内存管理**：实时释放已处理数据
- **异步加载**：setTimeout释放主线程
- **进度显示**：实时下载/解码进度提示

### 📱 移动端体验
- **自动全屏**：阅读时隐藏浏览器UI
- **触控优化**：章节导航栏智能显示/隐藏
- **响应式设计**：适配各种屏幕尺寸

### 🎨 阅读体验
- 中文排版优化（首行缩进/行高/分段）
- 章节导航系统（前进/后退/跳转）
- 夜间模式友好（继承系统配色）
- 纯净阅读界面（无干扰元素）

## 注意事项

1. **文件大小限制**：
   - 推荐 <50MB 文本文件
   - 超大数据量可能影响性能

2. **编码支持**：
   - 自动检测常见东亚编码
   - 非常见编码可能识别失败

3. **章节识别**：
   - 依赖标准标题格式
   - 非标准结构可能分章不准确

4. **移动端要求**：
   - 需要浏览器支持Fullscreen API
   - iOS需用户手动触发全屏
